# 🏡 Bishkek Real Estate Price Prediction

ML/Data Science проект по прогнозированию стоимости квартир в Бишкеке на основе характеристик недвижимости.

Проект включает:
- предобработку и очистку данных
- разведочный анализ данных (EDA)
- feature engineering
- обучение и сравнение ML-моделей
- оценку качества моделей

## 📌 Цель проекта

Цель проекта — построить модель машинного обучения, способную прогнозировать стоимость квартир в Бишкеке на основе параметров недвижимости.

Проект выполнен как ML/Data Science проект для портфолио с акцентом на:

- regression modeling
- feature engineering
- сравнение моделей машинного обучения
- построение ML pipeline
- оценку качества моделей

## 🤖 Используемые модели

Были обучены и сравнены следующие модели:

| Модель | Назначение |
|---|---|
| Linear Regression | Базовая линейная модель |
| Ridge Regression | L2-регуляризация |
| Lasso Regression | Отбор признаков через L1-регуляризацию |

Для подбора гиперпараметров использовался `GridSearchCV`.

---

## 📈 Метрики качества

Модели оценивались с помощью:
- RMSE
- MAE
- MAPE
- R² Score

Лучшие результаты показала модель Ridge Regressor.
